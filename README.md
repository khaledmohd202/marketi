# 🎥 About the App

Marketi is a modern e-commerce app that lets you browse products by categories and brands, manage your cart and favorites, and enjoy a smooth shopping experience with Dark & Light mode support.

**Key Features:**
- 🔍 **Search** for any product
- 🛒 **Cart Management** — add, remove, and checkout
- ❤️ **Favorites** — save your favorite products
- 🏷️ **Categories & Brands** browsing
- 🌓 **Dark & Light Theme** support
- 🔐 **Authentication** — Login, Sign Up, Forgot Password, OTP
- 📦 **Buy Again** & **Best for You** sections
- 📱 **20+ Screens** with clean UI

```bash
git clone https://github.com/khaledmohd202/marketi.git
```

### 2️⃣ Install Dependencies
```bash

```

### 3️⃣ Run the App
